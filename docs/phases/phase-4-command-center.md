# Phase 4: Command Center

**Status: PLANNED**

## Objective

A single home dashboard that shows what matters today across tasks, projects, agents, calendar, and email.

## Why it matters

It turns TaskForge into the place where the day starts, not just another app to check.

## Scope

A unified dashboard, today's priorities, tasks, projects, agent activity, calendar, email highlights, a morning briefing, and recommendations.

## Planned capabilities

- Unified home dashboard
- Today's priorities
- Tasks
- Projects
- Agent activity
- Calendar
- Email highlights
- Morning briefing
- Recommendations

## Dependencies

- Phase 2 (agents)
- Phase 3 (knowledge)
- A projects model, which does not exist yet
- Read-only calendar and email integrations

## Definition of done

The dashboard loads in one view with real data from each source. The morning briefing is generated by an agent and can be reviewed.

## Portfolio/career value

Shows product thinking: OAuth integrations, data aggregation, and dashboard UX.

## Cost constraints

Use free APIs only (for example, the Google Calendar and Gmail APIs within their free quotas). Generate the briefing with the local provider.

## Notes/decisions

- Calendar and email access start as read-only.
